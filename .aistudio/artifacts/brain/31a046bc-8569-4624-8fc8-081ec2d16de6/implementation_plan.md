# منظومة التوجيه السريري التلقائي من الحجز إلى الكشف والترحيل الآلي للملف العائلي (ف1 – ف10)

تحويل مسار حجز العيادات والكشف الطبي إلى دورة عمل ذكية ومترابطة تبدأ بتحديد نوع الزيارة والموديول الطبي تلقائياً فور اختيار العيادة عند الحجز، ثم تفتح للطبيب وقت الكشف النموذج المعتمد المطابق لبطاقة الملف العائلي لوزارة الصحة والتأمين الصحي الشامل (من **ف1** حتى **ف10**)، وترحّل كافة المخرجات السريرية تلقائياً إلى الملف العائلي للمريض فور حفظ الكشف.

---

## User Review & Critical Decisions

> [!IMPORTANT]
> **القرارات المعتمدة من إجاباتك في مرحلة التوضيح:**
> - **Confirmed Decision 1 (آلية تحديد نوع الحجز):** التحديد التلقائي لنوع الزيارة والموديول السريري بناءً على **تخصص العيادة المختارة** عند الحجز، مع ضبط النموذج الفرعي المناسب لخصائص المريض داخل ذلك التخصص (مثل التفرقة التلقائية بين طفل أقل من 5 سنوات **ف5أ/ب/ج** وطفل سن مدرسي 5–18 سنة **ف5د**، أو فحص الزوج **ف8أ** والزوجة **ف8ب**).
> - **Confirmed Decision 2 (نطاق النماذج الطبية في شاشة الكشف):** تغطية شاملة لجميع نماذج الملف العائلي المعتمدة (**ف1** إلى **ف10**) بحيث يفتح الكشف مباشرة على الحقول الرسمية المطلوبة لكل نموذج دون إجبار الطبيب على التعامل مع نموذج عام موحد.
> - **Confirmed Decision 3 (نطاق الترحيل التلقائي للملف العائلي):** ترحيل تلقائي فوري عند حفظ الكشف يشمل: **(1) جدول النموذج المختص**، و**(2) جدول التردد والزيارات (ف2ب)** شاملاً كود نوع الزيارة المعتمد (1 إلى 6)، و**(3) ملخص الأحداث الطبية الهامة والتاريخ المرضي المزمن للأسرة (ف2أ)**.

> [!WARNING]
> **الالتزام الصارم بقواعد قاعدة البيانات والأمان (القواعد 1 و2 و3 و4 و7):**
> - كما أوضحنا في فحص قاعدة البيانات الحية، يحتاج حفظ الكشف الشامل والنماذج التخصصية إلى استكمال الأعمدة الناقصة في قاعدة البيانات الحية (`clinical_findings` و`significant_events` في جدول الفحص العام، وأعمدة السن المدرسي في متابعة الطفل فوق 5 سنوات، وإسقاط `NOT NULL` عن `encounter_id`) مع إنشاء ملف Migration رسمي متطابق في نفس الجلسة، وباستخدام سياسات `TO authenticated` حصراً وبدون أي صلاحية `TO anon`.

## 1. Overview & Core Concept

- **What It Does:**
  1. **في شاشة حجز الموعد:** بمجرد اختيار المريض والعيادة، يستنتج النظام تلقائياً **نوع الحجز (Visit & Clinical Module Type)** من تخصص العيادة (مثل: عيادة الأطفال والرضع $\leftarrow$ متابعة طفل، عيادة رعاية الحوامل والنساء $\leftarrow$ متابعة الحمل/النفاس، عيادة تنظيم الأسرة $\leftarrow$ تنظيم الأسرة، عيادة الباطنة والأمراض المزمنة $\leftarrow$ متابعة ضغط/سكر/مزمن، عيادة الأسنان $\leftarrow$ فحص الأسنان، عيادة فحص راغبي الزواج $\leftarrow$ فحص ما قبل الزواج، عيادة المسنين $\leftarrow$ تقييم المسنين، عيادة طب الأسرة $\leftarrow$ الفحص الشامل أو متابعة الطفل حسب عمر المريض)، ويعرض لموظف الاستقبال متطلبات الحجز وما سيتم فتحه للطبيب.
  2. **في شاشة الكشف الطبي للطبيب:** عند ضغط الطبيب على **"تسجيل الكشف"** من قائمة انتظار العيادة، يقرأ النظام نوع الحجز المسجل وعمر/جنس المريض، ويفتح تلقائياً واجهة النموذج المعتمد المطابق من نماذج الملف العائلي (**ف1** حتى **ف10**).
  3. **عند حفظ الكشف (الترحيل التلقائي للملف العائلي):** بضغطة واحدة على **"حفظ الكشف وإتمام الزيارة"**، يتم حفظ البيانات في جدول النموذج التخصصي، وإدراج سجل التردد المرقم تلقائياً في **نموذج التردد (ف2ب)**، وتحديث **ملخص الأحداث الطبية الهامة (ف2أ)** وسجل الأمراض المزمنة لأفراد الأسرة.
- **Target Audience / Persona:** موظفو الاستقبال، أطباء طب الأسرة والأخصائيون، وطاقم التمريض في وحدات ومراكز صحة الأسرة.
- **Key Value:** القضاء التام على ازدواجية الإدخال أو فتح نماذج عامة غير مناسبة للحالة، وضمان تطابق السجل الإلكتروني للمريض والملف العائلي بنسبة 100% مع الدفتر الورقي المعتمد لوزارة الصحة والتأمين الصحي الشامل.

## 2. User Experience & Visual Design

### Key User Flows

1. **مسار الحجز التلقائي (Reception & Clinic Booking Flow):**
   - يختار موظف الاستقبال المريض ثم يختار العيادة.
   - يقوم النظام تلقائياً بتحديد **نوع الحجز والنموذج الطبي المستهدف** بناءً على تخصص العيادة وعمر/نوع المريض، ويعرض شارة واضحة توضح:
     - **نوع الزيارة في جدول التردد (ف2ب):** (`1- متابعة الحمل`، `2- تنظيم الأسرة`، `3- متابعة طفل`، `4- أمراض مزمنة`، `5- زيارة دورية / فحص شامل`، `6- أسنان`).
     - **النموذج السريري الذي سيُفتح للطبيب تلقائياً:** (مثل: `نموذج ف5أ/ب/ج: متابعة الطفل تحت 5 سنوات` أو `نموذج ف4أ/ب: متابعة الضغط والسكر` أو `نموذج ف6أ: متابعة الحمل`، إلخ).
   - يُحفظ هذا التوصيف المهيكل ضمن بيانات الموعد بحيث ينتقل بدقة إلى شاشة الطبيب.

2. **مسار الكشف الطبي التخصصي (Doctor Examination Flow — النماذج ف1 إلى ف10):**
   - فور فتح الكشف، يظهر للطبيب النموذج المعتمد المطابق لنوع الحجز مباشرة:
     - **نموذج ف1 (الفحص الشامل - History & Physical Examination):** للزيارات الدورية والفحص المبدئي الشامل، شاملاً التاريخ المرضي، التاريخ العائلي، الفحوصات المعملية الأساسية، والفحص السريري لأجهزة الجسم.
     - **نموذج ف3 (فحص وعلاج الأسنان - Dental Form):** لعيادة الأسنان، شاملاً الفحص خارج وداخل الفم، تقييم مفصل الفك (TMJ)، الغشاء المخاطي، مؤشر اللثة (CPI)، فلورة الأسنان، وحالة الأسنان (DMFT).
     - **نماذج ف4أ / ف4ب / ف4ج (متابعة الأمراض المزمنة - ضغط / سكر / أمراض مزمنة أخرى):** لعيادات الباطنة والأمراض المزمنة، شاملاً قياسات الضغط (جلوس/وقوف)، عوامل الخطورة، المضاعفات، الفحوصات الدورية (كل زيارة / 6 شهور / سنوياً مثل HbA1c، الدهون، قاع العين، فحص القدم السكري)، التثقيف الصحي، وخطة العلاج.
     - **نماذج ف5أ / ف5ب / ف5ج (متابعة الطفل تحت 5 سنوات):** لعيادة الأطفال أو طب الأسرة للأطفال دون 60 شهراً، شاملاً محطات العمر بالشهور (حتى شهرين، 2، 4، 6، 9، 12، 18، 24، 36، 48، 60 شهراً)، الوزن، الطول، محيط الرأس، الهيموجلوبين، نوع الرضاعة والفطام، التطعيمات الإجبارية وفيتامين أ و د، علامات التطور الحركي والذهني، الحالات الخاصة، ومخاوف الوالدين.
     - **نموذج ف5د (متابعة الطفل فوق 5 سنوات - السن المدرسي 5 إلى 18 سنة):** شاملاً المرحلة الدراسية (حضانة، أولى/ثانية/رابعة ابتدائي، أولى إعدادي، أولى ثانوي)، الوزن والطول ومؤشر كتلة الجسم، نوع التطعيم (ثنائي/سحائي)، حدة الإبصار والسمع، الفحص النفسي والسلوكي، والتحصيل الدراسي.
     - **نموذج ف6أ و ف6ب (متابعة الحمل ومتابعة ما بعد الولادة والنفاس):** لعيادة رعاية الحوامل والنساء، شاملاً تاريخ آخر دورة (LMP)، تاريخ الولادة المتوقع (EDD)، التيتانوس، تقييم الجنين (مستوى الرحم، وضع الجنين، نبض وحركة الجنين، السونار)، التحاليل (هيموجلوبين، سكر، بول)، أو تقييم النفاس والرضاعة الطبيعية واكتئاب ما بعد الولادة ووسيلة تنظيم الأسرة.
     - **نموذج ف7 (منتفعة بخدمات تنظيم الأسرة):** لعيادة تنظيم الأسرة، شاملاً التاريخ الإنجابي، بيانات الدورة الشهرية، بيانات الوسيلة الحالية/السابقة، الفحص الحوضي وعنق الرحم، والوسيلة المنصرفة.
     - **نموذج ف8أ و ف8ب (تقييم المقبلين على الزواج للزوج والزوجة):** لعيادة فحص راغبي الزواج، شاملاً صلة القرابة، الأمراض المعدية والوراثية، الفحوص الإجبارية (سكر، صورة دم، Rh، أشعة صدر) والتكميلية (HCV, HBV, HIV, Thalassemia)، التوصيات الطبية، وإقرار المنتفع.
     - **نموذج ف9 (تقييم المسنين - Geriatric Assessment):** لمن هم 60 سنة فأكثر، شاملاً تقييم الوهن (Frailty)، الوظائف الأساسية والفعالة والمتقدمة (ADLs / IADLs)، المزاج والاكتئاب، التنقل واختبار الوقوف والمشي، الحواس، سلس البول، مسح الأورام وهشاشة العظام، التطعيمات، واختبار Mini-Cog.
     - **نموذج ف10أ و ف10ب (الإحالة والإحالة العكسية):** إمكانية تسجيل إحالة المريض لمستشفى/استشاري أثناء الكشف مع سبب الإحالة ودرجة الاستعجال (Emergency / Urgent / Non-urgent) والتشخيص المبدئي.

3. **مسار الترحيل التلقائي للملف العائلي (Auto-Sync to Family Health Record):**
   - عند حفظ الطبيب للكشف، يعرض النظام ملخصاً واضحاً لما يتم ترحيله تلقائياً بدون تدخل يدوي إضافي:
     1. حفظ سجل النموذج التخصصي المرتبط بالموعد.
     2. إنشاء قيد في **نموذج التردد (ف2ب)** يحتوي على: التاريخ، كود الزيارة الرسمي (1 إلى 6)، الشكوى، الفحص السريري، الفحوصات، التشخيص، خطة العلاج والمتابعة، وتوقيع الطبيب.
     3. إذا تضمن الكشف حدثاً طبياً هاماً أو تشخيصاً مزمناً جديداً أو إحالة أو إجراءً علاجياً بارزاً، يُسجّل تلقائياً في **ملخص الأحداث الطبية الهامة (ف2أ - Significant Data Sheet)** وفي جدول التاريخ المرضي لأفراد الأسرة ببطاقة الملف العائلي.

### Visual Identity & Theme
- **Aesthetic Direction:** واجهة طبية مؤسسية عالية الوضوح والانضباط (Clinical Enterprise Workspace) تدعم اتجاه القراءة من اليمين لليسر (RTL) مع تباين لوني دلالي واضح لكل فئة من نماذج الملف العائلي.
- **Color Palette & Mood:**
  - خلفية عمل محايدة ونظيفة (`#F8FAFC` / `#FFFFFF`) مع حدود دقيقة (`border-slate-200`).
  - ألوان دلالية مميزة لرأس كل نموذج طبي: الأخضر الزمردي لرعاية الطفل (`ف5`)، الوردي الهادئ لرعاية الأمومة وتنظيم الأسرة (`ف6` و`ف7`)، الكحلي الرصين للفحص الشامل والأمراض المزمنة (`ف1` و`ف4`)، البنفسجي لتقييم المسنين وفحص ما قبل الزواج (`ف8` و`ف9`)، والسماوي لفحص الأسنان (`ف3`).
- **Typography & Hierarchy:** خط عربي واضح للبيانات السريرية مع استخدام الأرقام الجدولية (`font-mono tabular-nums`) لكافة القياسات الحيوية (الضغط، الوزن، الطول، محيط الرأس، العمر بالشهور، ومؤشر كتلة الجسم).

## 3. Key Product Decisions & Trade-Offs

- **Decision 1: التحديد التلقائي لنوع الحجز من تخصص العيادة مع الذكاء العمري/النوعي**
  - *Chosen Approach:* ربط كل عيادة تلقائياً بنوع الزيارة والنموذج الطبي المقابل لها فور اختيارها في شاشة الحجز، مع تخصيص النموذج الفرعي تلقائياً حسب عمر وجنس المريض (مثلاً: عيادة الأطفال أو طب الأسرة مع طفل $< 5$ سنوات تفتح `ف5أ/ب/ج`، ومع طفل $5-18$ سنة تفتح `ف5د`؛ وعيادة فحص الزواج مع ذكر تفتح `ف8أ` ومع أنثى تفتح `ف8ب`).
  - *Why:* يلبي اختيارك بعدم إرهاق موظف الاستقبال بقوائم يدوية معقدة، ويضمن في الوقت نفسه أن يفتح النظام للطبيب النموذج الفرعي الدقيق المناسب لعمر وجنس المريض.
- **Decision 2: شاشة كشف موحدة متعددة النماذج مع إمكانية إضافة إحالة (ف10أ) في نفس الجلسة**
  - *Chosen Approach:* دعم جميع النماذج المعتمدة داخل شاشة كشف الطبيب مباشرة مع شريط تبديل سريع للطبيب إذا احتاج لمراجعة أو استكمال نموذج إضافي (مثل فتح نموذج الإحالة `ف10أ` أثناء كشف أمراض مزمنة أو متابعة حمل خطر).
  - *Why:* يمنح الطبيب سرعة فائقة في التسجيل من مكان واحد دون التنقل بين نوافذ متعددة.
- **Decision 3: محرك ترحيل تلقائي ثلاثي المسار (Triple Auto-Write-Back Engine)**
  - *Chosen Approach:* تحديث محرك العمليات السريرية ليرحّل مخرجات أي كشف تلقائياً إلى 3 مسارات متوازية: الجدول التخصصي للنموذج، سجل التردد `ف2ب` بكود الزيارة المعتمد (1–6)، وسجل الأحداث الطبية الهامة `ف2أ` / التاريخ المرضي للأسرة.
  - *Why:* يضمن أن الملف العائلي للمريض يظل محدثاً لحظياً بكل زيارة وتشخيص وقياس حيوي دون أي إدخال مزدوج.

## 4. Technical Architecture & Data Strategy

### Architecture & Data Flow Diagram

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ 1. شاشة حجز الموعد (QuickClinicBookingModal / Reception / Clinics)            │
│    • اختيار المريض + اختيار العيادة                                          │
│    • محرك استنتاج نوع الحجز التلقائي (Auto-Resolve Visit & Form Type)         │
│      ├─ تخصص العيادة + عمر/جنس المريض ──► تحديد كود التردد (1..6)             │
│      └─ تحديد النموذج الطبي المستهدف (ف1، ف3، ف4أ/ب/ج، ف5أ/د، ف6أ/ب، ف7، ف8، ف9)│
└──────────────────────────────────────┬───────────────────────────────────────┘
                                       │ حفظ الموعد + توصيف النموذج المستهدف
                                       ▼
┌──────────────────────────────────────────────────────────────────────────────┐
│ 2. شاشة الكشف الطبي للطبيب (ClinicExaminationModal)                          │
│    • قراءة نوع الحجز والنموذج المستهدف تلقائياً عند فتح الكشف                 │
│    • عرض حقول النموذج المختص مباشرة:                                         │
│      ├─ [ف1] الفحص الشامل والتاريخ المرضي والعائلي والفحص السريري             │
│      ├─ [ف3] فحص الأسنان واللثة (CPI & DMFT & TMJ)                           │
│      ├─ [ف4أ/ب/ج] متابعة الضغط / السكر / الأمراض المزمنة الأخرى               │
│      ├─ [ف5أ/ب/ج] متابعة الطفل تحت 5 سنوات (نمو، رضاعة، تطعيمات، تطور)       │
│      ├─ [ف5د] متابعة الطفل فوق 5 سنوات (السن المدرسي والفحص السلوكي)          │
│      ├─ [ف6أ/ب] متابعة الحمل (ANC) / متابعة ما بعد الولادة والنفاس            │
│      ├─ [ف7] تنظيم الأسرة والصحة الإنجابية                                   │
│      ├─ [ف8أ/ب] فحص ما قبل الزواج (للزوج / للزوجة) + الإقرار                 │
│      ├─ [ف9] التقييم الشامل للمسنين (Frailty, ADLs, Mini-Cog, Screening)     │
│      └─ [ف10أ] نموذج الإحالة للمستشفى / الاستشاري (عند الحاجة للإحالة)       │
└──────────────────────────────────────┬───────────────────────────────────────┘
                                       │ ضغط "حفظ الكشف وإتمام الزيارة"
                                       ▼
┌──────────────────────────────────────────────────────────────────────────────┐
│ 3. محرك الترحيل التلقائي للملف العائلي (HospitalOperationalEngine)           │
│    ├──► (أ) حفظ السجل في الجدول التخصصي المقابل للنموذج (ف1..ف10)            │
│    ├──► (ب) ترحيل تلقائي إلى نموذج التردد (ف2ب - patient_visits):            │
│    │         [التاريخ + كود الزيارة (1..6) + الشكوى + الفحص + التحاليل        │
│    │          + التشخيص + خطة العلاج + توقيع الطبيب]                         │
│    └──► (ج) ترحيل تلقائي إلى ملخص الأحداث الطبية الهامة (ف2أ) والتاريخ       │
│              المرضي لأفراد الأسرة (significant_events & problem_list)        │
└──────────────────────────────────────────────────────────────────────────────┘
```

| تخصص العيادة المختارة عند الحجز | شرط العمر / الجنس الإضافي | كود التردد (ف2ب) | النموذج الذي يُفتح تلقائياً للطبيب | الجداول التي يُرحّل إليها تلقائياً عند الحفظ |
| :--- | :--- | :---: | :--- | :--- |
